# Google Analytics Capstone Case Study: Bellabeat

This repository contains the final project for the Google Analytics Professional Certificate program, 
a case study exploring smart device user data to provide data-driven insights and recommendations.

## Project Overview

The goal of this case study was to apply the data analysis principles and tools learned in 
the Google Analytics program to a real-world business problem. 
The project involved analyzing data, identifying key trends, and providing actionable recommendations to marketing strategy.
The tool of choice is R programming language.

## Case Study Question

What are some trends in smart device usage?
How could these trends apply to Bellabeat customers?
How could these trends help influence Bellabeat marketing strategy?

## Repository Structure

This repository is organized to reflect the different stages and components of the case study:

* `AI_research/`: Contains the research on the average daily exercise time of the US people.
* `asset/`: Includes assets used in the project e.g., images, logos, presentation templates.
* `code/`: Contains scripts and queries used for data cleaning, transformation, and analysis (R scripts).
* `data/`: Stores the datasets used for the analysis. this contains both raw or cleaned data. Note: large files are handled by LFS.
* `documentation/`: Includes project documentation (mergin, cleaning, transformation).
* `metadata/`: Contains metadata related to the datasets.
* `Case Study 2_ How-can-a-wellness-technology...`: The document outlining the case study details.
* `final_report.pptx`: The presentation file summarizing the key findings and recommendations.

## Tools and Skills Applied

## Key Findings & Recommendations
### Key Findings 
1. Fitbit users demonstrate a higher level of physical activity compared to the average person. Additionally, an examination of their sleep habits indicates that Fitbit users are health-conscious .
2. The activity profile shifts toward light activities. Moderate and very active physical activities are noticeable but to a lesser extent.

### Recommendations
1. The time window for ads is from 15:00 to 17:00, in which people would have finished their work-out or prepared for one. 
(high level of motivation, high level of contentment, problem-product association, etc.)
2. The ads content should show a healthy and active lifestyle in which light physical activities (a large ads portion) and 
moderate/heavy physical activities (a smaller ads portion) are the focus.
